このポリシーは、Hiro 個人が自分の業務の自動化のために使っているツール「Nova」が、Google アカウントのデータをどのように扱うかを定めたものです。Nova は個人用であり、利用するのは Hiro 本人だけです。

1. 取得する Google のデータ

  • Google カレンダー（読み取りと書き込み）：予定の内容と日時を読み取ります。また、本人の予定の整理のために、予定や専用のカレンダーを作成・更新・削除します。

Google の連絡先など、上記以外のデータには、アクセスしません。

2. 利用の目的

取得したデータは、Hiro 本人の業務と生活の自動化（予定の整理、時間枠の作成、通知の統一など）の目的にのみ使います。広告、販売、解析、その他の目的には使いません。

3. 第三者への提供

取得したデータを、第三者に提供、販売、貸与することはありません。

なお、本人の予定の整理のために、本人が契約して利用する AI アシスタントのサービスに、カレンダーの内容を入力して処理を依頼することがあります。これは本人自身の利用であり、それ以外の第三者に提供するものではありません。

4. 保存の場所と期間

認証情報（アクセスに必要な鍵）は、本人が管理するサーバーに保存し、外部に公開しません。取得したデータは、上の目的に必要な範囲でのみ扱い、必要がなくなったものは保存しません。

5. Google API サービスのユーザーデータに関するポリシーの遵守

Nova による Google API から受け取った情報の利用と、他のアプリへの転送は、限定的な使用の要件を含む、Google API サービスのユーザーデータに関するポリシーに準拠します。

6. アクセスの取り消しとデータの削除

Hiro 本人は、いつでも、Google アカウントの「サードパーティによるアクセス」の設定から、Nova へのアクセス許可を取り消せます。取り消すと、Nova は Google のデータに一切アクセスできなくなります。保存している認証情報も、あわせて削除します。

7. このポリシーの変更

このポリシーを変更するときは、このページを更新し、上の「最終更新日」を改めます。
